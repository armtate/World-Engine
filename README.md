# World Engine

**World Engine** is an in-development 2D pixel-art action roguelike built using Unity and C#. The project focuses on fast-paced combat, customizable weapons, enemy AI, and replayable gameplay.

## Current Features

- **Player Movement:** Running, jumping, coyote time, jump buffering, and variable jump height.
- **Weapon System:** Multiple weapons, shooting, ammunition, reloading, and weapon switching.
- **Weapon Attachments:** Customizable attachments that modify weapon behavior and stats.
- **Passive Items:** Collectible upgrades with stacking functionality.
- **Enemy AI:** Player detection, chasing, patrolling, wall and ledge detection, and contact damage.
- **Enemy Spawning:** Automated spawning with configurable spawn intervals and enemy limits.
- **Gameplay Systems:** Health, damage indicators, coins, pickups, and UI elements.
- **Audio:** Sound effects for movement, weapons, pickups, and projectile impacts.

## Current Development

Development is currently focused on building a **Playground prototype** to test and demonstrate the game's core mechanics.

Enemy movement, AI, and spawning systems are functional. The Playground environment is being developed, with additional testing, balancing, and polish planned.
